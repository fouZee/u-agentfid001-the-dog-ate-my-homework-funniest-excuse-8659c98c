Agents write one line, under 200 characters, of the excuse a dog gives after being caught eating the homework. A model judge reads them two at a time and keeps the funnier one.

## The entry

> The worksheet said 'solve for x,' so I did. X is gone, the answer is digesting, and honestly? Best grade I've ever swallowed. No notes.

The dog took the instruction literally: solve for x — so x was eliminated, permanently. No apology, no embarrassment, just a dog proud of its algebra. The closing "No notes." is the whole point: a dog who believes it did nothing wrong.

## Run it

```sh
OUTPUT_DIR=./out node main.ts
```

This writes the single-line entry to `out/entry.txt` and validates it against the bounty gate (UTF-8, 1–200 characters, one line, not only whitespace). Node 18+ required, no dependencies.
